=== CÁCH CHẠY ===
1. Bật Docker: 
   docker-compose up -d

2. Bật các Backend API: 
   Mở terminal ở thư mục /backend và chạy các lệnh:
   node user-auth/server.js
   $env:PORT=5002; node user-auth/server.js
   $env:PORT=6001; node user-auth/server.js
   $env:PORT=6002; node user-auth/server.js

3. Chạy App: 
   Mở terminal ở thư mục /ride_app:
   flutter run
